Audio · Vidéo · Photographie

Vos médias,
en clair.

Consultez les informations techniques et modifiez les métadonnées prises en charge dans une interface de terminal pilotée au clavier.

1. Ouvrir un fichier

Double-cliquez sur odmedia.exe, puis collez ou glissez le chemin d'un fichier dans le terminal et appuyez sur Entrée. Vous pouvez aussi passer le chemin directement :

odmedia "C:\Media\ma vidéo.mp4"

Commencez par Overview, la vue d'ensemble. Tab parcourt les rubriques et / recherche un champ. Entrée affiche une valeur complète ou ouvre un champ modifiable. L'aide est accessible avec F1, y compris pendant la saisie d'un chemin.

Les libellés de l'application sont en anglais ; ce guide reprend leurs noms pour vous aider à les retrouver.

Pour changer de fichier, appuyez sur Ctrl + O ou choisissez Open another file… dans F4 → Actions. Glissez le fichier suivant dans le terminal et appuyez sur Entrée. Si le fichier ne s'ouvre pas, essayez un autre chemin ou appuyez sur Échap à l'invite pour revenir au fichier courant. Si le nouveau fichier est lisible et que des modifications sont en attente, choisissez Save pour les enregistrer, Discard pour les abandonner ou Cancel pour rester sur le fichier courant.

2. Trouver la bonne information

Les rubriques dépendent du fichier et des données disponibles :

  • Video / Audio : codecs, dimensions, cadences, débits, fréquence d'échantillonnage, canaux et détails des pistes.
  • Image / Capture / Location : dimensions, appareil, objectif, focale, temps de pose, ouverture, ISO, dates et GPS.
  • Subtitles / Chapters : sous-titres, langues, pistes par défaut ou forcées et horodatages des chapitres.
  • Metadata / Images : tags descriptifs, auteurs, copyright et pochettes intégrées.
  • Color / Advanced : informations colorimétriques, EXIF/IPTC/XMP et champs d'origine des lecteurs, lorsqu'ils sont disponibles.

Les tableaux techniques présentent une valeur et sa source. Les textes longs sont raccourcis dans la grille ; Entrée ouvre leur détail défilant. La recherche porte sur les noms, valeurs et sources de toutes les rubriques. Relancez la recherche et videz sa saisie pour retirer le filtre.

Une valeur absente ne signifie pas zéro. La couverture dépend du fichier, du format et du lecteur. Le nombre d'images indiqué par l'en-tête est identifié comme déclaré ; les débits estimés sont signalés comme tels.

3. Plusieurs modifications, un enregistrement

La grille distingue Saved value (valeur enregistrée) et Pending value (valeur en attente). Les remplacements apparaissent en jaune, les suppressions en rouge et le nom du champ sélectionné en cyan. Le badge jaune unsaved changes compte les modifications de toutes les rubriques, y compris les changements de pochette et ceux que le filtre masque. Save ressort sur fond vert lorsque des modifications sont en attente. La confirmation présente les valeurs Before et After.

  1. Sélectionnez une ligne modifiable et appuyez sur Entrée. Corrigez sa valeur, puis validez avec Entrée ; Échap annule la saisie.
  2. Continuez dans d'autres lignes ou rubriques. Rien n'est encore enregistré.
  3. Appuyez sur Ctrl + S ou F6 pour revoir toutes les opérations en attente. Les flèches font défiler le récapitulatif ; Entrée enregistre l'ensemble et Échap revient à la grille.
Keep · Conserver

La valeur actuelle sera conservée.

Replace · Remplacer

La nouvelle valeur sera écrite.

Remove · Supprimer

Le champ sera effacé si le format le permet.

Suppr prépare une suppression. Ctrl + Z rétablit la ligne sélectionnée. Une saisie vide ou composée d'espaces conserve son état en attente ; utilisez l'action explicite de suppression pour effacer un champ.

Séparez les listes par des points-virgules : Alice; Bob. Utilisez le point décimal : 2.8. Le temps de pose accepte 1/125 seconde. Les dates de l'appareil suivent yyyy-MM-dd HH:mm:ss, sans fuseau horaire supposé. Ctrl + Entrée insère un saut de ligne ; Ctrl + A vide la saisie.

Les données de prise de vue et le GPS sont initialement verrouillés. Pour corriger les valeurs prises en charge, choisissez F4 → Enable capture and GPS editing. Modifier ces tags ne change ni les pixels ni l'exposition réelle de la photo.

Protection à l'enregistrement

L'enregistrement utilise une copie temporaire et vérifie par relecture les modifications de la grille avant de remplacer l'original. Le premier fichier .bak est conservé ; il n'est pas actualisé à chaque enregistrement. La création de sauvegarde et la conservation de la date de modification se règlent dans F4 → Actions. Un échec conserve les changements en attente.

Pochettes et presets

F4 permet d'ajouter, remplacer, retirer ou extraire une pochette. Les pochettes sont limitées à 10 Mo et intégrées sans redimensionnement.

Pour un fichier audio ou vidéo modifiable, choisissez Preset: create from this file, Preset: create from scratch ou Preset: stage for this file dans F4 → Actions. Cette dernière commande prépare les changements dans la grille pour les revoir et les enregistrer. Preset: manage permet de lister les presets, de consulter leurs détails ou de les supprimer. L'export JSON et la création d'un preset depuis le fichier utilisent les valeurs enregistrées.

Les presets sont stockés dans le dossier presets à côté de l'exécutable. Définissez ODMEDIA_PRESET_DIR pour partager ce dossier entre plusieurs copies d'odmedia.

L'essentiel en ligne de commande

Exécutez ces commandes depuis le dossier de l'exécutable ou ajoutez ce dossier au PATH. Dans PowerShell, utilisez .\odmedia.exe à la place d'odmedia si l'application n'est pas dans le PATH.

odmedia info "clip.mp4"
odmedia info "clip.mp4" --json
odmedia info "clip.mp4" --analyze-cadence
odmedia set "musique.mp3" --title "Nouveau titre" --artist "Alice; Bob"
odmedia set "musique.mp3" --title "Aperçu" --dry-run
odmedia preset list
odmedia preset apply "musique.mp3" --name "Mon preset" --dry-run
odmedia manual --lang fr
odmedia manual --lang en --no-open
odmedia --help

--json exporte les résultats techniques et les tags. --dry-run n'enregistre rien. Lorsqu'elles sont proposées, --no-backup désactive la création de sauvegarde et --keep-mtime conserve la date de modification. Le mode interactif exige un terminal ; utilisez info --json pour une sortie redirigée.

odmedia clear "fichier.mp3" --yes retire tous les blocs de tags pris en charge. Réservez cette commande aux cas où vous souhaitez effacer les métadonnées du fichier.

Analyseur et intégration à l'Explorateur

Obtenir les détails audio et vidéo étendus

odmedia tools status
odmedia tools install

Vous pouvez aussi choisir F4 → Install media analyzer. Le téléchargement nécessite Internet. FFmpeg et FFprobe sont installés à côté de l'exécutable après vérification SHA-256 ; les outils déjà présents sont conservés. Aucun droit administrateur ni changement du PATH n'est nécessaire. Échap annule le téléchargement interactif.

La détection examine d'abord ODMEDIA_FFPROBE, puis le dossier de l'exécutable et enfin le PATH. Sans FFprobe, la lecture photo intégrée et les informations natives disponibles restent accessibles. F4 → Analyze cadence examine les horodatages d'au plus 300 images de la première piste vidéo. Une cadence uniforme dans cet échantillon ne certifie pas une cadence constante sur tout le fichier.

Ouvrir un fichier depuis l'Explorateur

odmedia explorer install
odmedia explorer remove

Dans l'espace interactif, F4 → Actions propose Add Explorer context menu et Remove Explorer context menu. L'inscription ajoute Inspect metadata with odmedia pour votre compte Windows, sans droits administrateur ni modification des applications par défaut. La commande ouvre un seul fichier sélectionné dont l'extension correspond à un format pris en charge. Des formats supplémentaires comme MOV sont inscrits lorsque FFprobe est disponible.

Trouver la commande sous Windows 11

  • Faites Maj (Shift) + clic droit sur un fichier multimédia pour ouvrir directement le menu contextuel classique. Choisissez Inspect metadata with odmedia.
  • Un clic droit sans Maj ouvre le menu moderne. Choisissez Afficher d’autres options ou Afficher plus d’options selon le libellé de votre version de Windows, puis Inspect metadata with odmedia.
Lorsqu’il apparaît, le sous-menu Applications extensions présente une sélection d’extensions prises en charge par le menu moderne. L’inscription actuelle d’odmedia vise le menu classique. Il est donc normal que la commande soit absente de cette liste.

Activez la commande depuis l'emplacement définitif de l'exécutable. Relancez l'inscription si vous déplacez l'exécutable ou installez l'analyseur facultatif. L'inscription et la désinscription suppriment l'ancienne entrée globale.

Compiler depuis les sources

Dans le dépôt source, double-cliquez sur Publish.BAT dans l'Explorateur pour lancer build.ps1. La compilation produit publish\odmedia.exe et laisse la fenêtre ouverte pour lire le résultat. Le SDK .NET 10.0.400 ou une version ultérieure compatible est nécessaire.

Aide et limites pratiques

Certains champs ne sont pas modifiables

Les dimensions, codecs et cadences sont des propriétés techniques : les changer exige un traitement du média. Les RAW et les formats d'image non pris en charge sont consultables seulement. La lecture RAW dépend de l'appareil et du format. Les modifications JPEG, PNG et TIFF sont disponibles uniquement si le moteur les prend en charge et si elles passent la vérification par relecture.

Le terminal est trop petit

Utilisez un terminal d'au moins 76 colonnes sur 18 lignes. Agrandissez la fenêtre ou réduisez la taille de sa police. Entrée affiche les valeurs longues.

L'installation ou l'extraction du manuel est refusée

Déplacez odmedia.exe dans un dossier où vous pouvez écrire, puis recommencez. Les outils et les manuels sont placés à côté du véritable exécutable, y compris dans la version autonome.

Comment retrouver l'original ?

Fermez le fichier dans l'application et copiez son .bak vers un autre fichier média pour l'examiner. La sauvegarde contient la version antérieure au premier enregistrement avec sauvegarde, pas nécessairement celle qui précède le dernier enregistrement.

Ce manuel est embarqué dans odmedia.exe. odmedia manual choisit le français pour une interface système française, sinon l'anglais. Les deux fichiers HTML sont extraits pour permettre le changement de langue hors ligne. Un nouvel appel à l'aide les actualise depuis la version embarquée ; conservez vos notes personnelles dans un autre fichier.
