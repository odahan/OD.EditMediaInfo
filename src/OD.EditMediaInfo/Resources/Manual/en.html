Audio · Video · Photography

Your media,
clearly documented.

Inspect technical information and edit supported metadata in a keyboard-driven terminal workspace.

1. Open a file

Double-click odmedia.exe, then paste or drag a file path into the terminal and press Enter. You can also pass a path directly:

odmedia "C:\Media\my video.mp4"

Start with Overview. Press Tab to browse sections, or / to find a field. Press Enter to inspect a complete value or edit a supported field. Help is available with F1, including while entering a path.

To switch files, press Ctrl + O or select Open another file… in F4 → Actions. Drop the next file into the terminal and press Enter. Press Esc at the path prompt to return to the current file. When the next file is ready, Save, Discard, or Cancel handles any pending edits.

2. Find the right information

Sections appear according to the file and available data:

  • Video / Audio: codecs, dimensions, frame rates, bitrates, sample rate, channel layout and track details.
  • Image / Capture / Location: dimensions, camera, lens, focal length, exposure, aperture, ISO, dates and GPS.
  • Subtitles / Chapters: subtitle tracks, languages, default/forced flags and chapter timing.
  • Metadata / Images: descriptive tags, authors, copyright and embedded artwork.
  • Color / Advanced: color properties, EXIF/IPTC/XMP and original reader fields, when available.

Technical tables show a value and its source. Long text is shortened on screen; Enter opens a scrollable detail view. Search spans field names, values and sources across every section. Open search again and clear its input to remove the filter.

An absent value does not mean zero. Coverage depends on the file, format and reader. Header frame counts are declared counts; estimated bitrates are labelled as estimates.

3. Edit several fields, then save once

  1. Select an editable row and press Enter. Adjust its text and accept with Enter; Esc cancels the editor.
  2. Continue in other rows or sections. Nothing is saved yet.
  3. Press Ctrl + S or F6 to review all pending operations. Scroll with the arrow keys; press Enter to save all, or Esc to go back.
Keep

The current value is preserved.

Replace

The new value will be written.

Remove

The field will be deleted where supported.

Delete stages a removal. Ctrl + Z reverts the selected row. Empty or whitespace-only editor input leaves its pending state unchanged; use the explicit removal action to erase a field.

Lists use semicolons: Alice; Bob. Numbers use a decimal point: 2.8. Exposure accepts 1/125 seconds. Camera dates use yyyy-MM-dd HH:mm:ss, without an inferred timezone. Ctrl + Enter inserts a line break; Ctrl + A clears the editor input.

Photo capture and GPS fields are locked initially. To correct supported values, use F4 → Enable capture and GPS editing. Changing these tags does not alter the pixels or the original exposure.

Save protection

Saving uses a temporary copy and checks that grid edits survive a read-back before replacing the original. The first .bak is preserved; it is not updated on every save. Backup creation and modification-time preservation can be toggled under F4 → Actions. Failed saves retain pending changes.

Artwork and presets

Use F4 to add, replace, remove or extract artwork, or manage presets. Applying a preset stages changes before saving. Artwork is limited to 10 MB and is embedded without resizing. JSON export and preset creation from the current file use saved values, excluding pending edits.

Command-line essentials

Run these commands from the executable folder, or add that folder to PATH. In PowerShell, use .\odmedia.exe instead of odmedia if it is not on PATH.

odmedia info "clip.mp4"
odmedia info "clip.mp4" --json
odmedia info "clip.mp4" --analyze-cadence
odmedia set "song.mp3" --title "New title" --artist "Alice; Bob"
odmedia set "song.mp3" --title "Preview" --dry-run
odmedia preset list
odmedia preset apply "song.mp3" --name "My preset" --dry-run
odmedia manual --lang en
odmedia manual --lang fr --no-open
odmedia --help

--json exports technical results and tags. --dry-run does not save. Where offered, --no-backup disables backup creation and --keep-mtime preserves file modification time. Interactive mode needs a real terminal; use info --json for redirected output.

odmedia clear "file.mp3" --yes removes all supported tag blocks from the file. Use it only when you intend to erase the file's metadata.

Analyzer and Explorer integration

Get extended video/audio details

odmedia tools status
odmedia tools install

Or choose F4 → Install media analyzer. Internet access is needed for the download. FFmpeg and FFprobe are installed beside the executable after SHA-256 verification; existing tools are preserved. No administrator rights or PATH changes are required. Esc cancels an interactive download.

Detection checks ODMEDIA_FFPROBE first, then the executable folder, then PATH. Without FFprobe, built-in photo reading and available native media information remain accessible. To sample actual video timing, use F4 → Analyze cadence. This checks up to 300 frames from the first video track; uniform sampled timing does not certify the entire file as constant-rate.

Open files from Explorer

odmedia explorer install
odmedia explorer remove

These actions are also available under F4. The per-user entry Inspect metadata with odmedia opens one selected file with a supported media extension. Additional formats such as MOV are registered when FFprobe is available. On Windows 11, use Show more options. Install the entry from the executable's permanent location; register again if you move it or install the optional analyzer. Both actions remove the previous all-files entry.

Help and practical limits

Some fields cannot be edited

Dimensions, codecs and frame rate are technical properties: changing them requires media processing. RAW and unsupported image formats are inspection-only. RAW metadata coverage varies by camera and format. JPEG, PNG and TIFF edits are available only where the writer supports them and changes survive verification.

The terminal is too small

Use a terminal of at least 76 columns × 18 rows. Enlarge its window or reduce its font size. Long values can be inspected with Enter.

Installation or manual extraction is denied

Move odmedia.exe to a folder you can write to and retry. The analyzer and manuals are placed beside the actual executable, including for the self-contained build.

How do I recover the original?

Close the file in the application and copy its .bak to a separate media file to inspect it. The backup contains the version from before the first backed-up save, not necessarily the version from the immediately preceding save.

This manual is embedded in odmedia.exe. odmedia manual selects French for a French system UI, otherwise English. Both HTML files are extracted so the language link works offline. They are refreshed from the embedded version when help is called; keep personal notes in another file.
